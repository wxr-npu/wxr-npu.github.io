# 指针函数
指针函数就是**指针的函数**，是个函数，是一个返回值为指针的函数。
什么叫指针的函数呢？为了便于理解，笔者自己引入了一下的概念。（注意这只是便于理解，而且是笔者自己想的，如果有问题还请指正）
首先先从函数来说起，函数可以分为两种，一种是有返回值的，一种是没有返回值的（void声明）。
在有返回值这一类函数中，有int、float等等，因为这一类**函数执行完毕后相当于他的返回值占据了函数名称的位置**，如下

```c
int add(int a , int b)
{
	return a+b;
}

int main
{
	int c = add(1,2);//这里相当于1+2这个int值占据了add(1,2)这个位置
}
```
所以我们可以说例子当中的函数是个int的函数。
明确了这个概念之后，接下来我们来理解**指针的函数**这个概念，指针的函数也就是说函数的返回值是个指针。一个指针代替了原来函数的位置。
## 语法

> 返回类型* 函数名(参数列表);

例如：

```c
int* createArray(int size)
{
    int* arr = (int*)malloc(size * sizeof(int));
    for (int i = 0; i < size; i++) 
    {
        arr[i] = i + 1;//这里的arr[i]相当于*(arr+i)，如果不懂可以去看我的上一篇博客
    }
    return arr;  // 返回指向动态分配数组的指针
}
```
函数的返回值（属性）是一个指针，这个指针的类型（属性）是整型int。

## 指针函数的工程应用---malloc与new
malloc作为内存分配的重要函数，其在<stdlib.h>文件中，函数原型是

```c
void *malloc(size_t );
```
malloc就是一个返回值为void*的指针的指针函数。
new函数同理，函数原型如下：

```c
void* operator new (size_t );
```
new也是一个返回值为void*的指针的指针函数。
# 函数指针
函数指针可以理解为**函数的指针**，是个指针，是一个指向函数的指针。

## 函数的地址
指针和地址是分不开的，我们要理解函数的指针首先先要了解函数的地址。
在程序编译时，函数的地址是如何确认的呢？首先编译器将每个源文件（.c 或 .cpp）编译成目标文件（.o 或 .obj）时，在目标文件中，函数的地址是相对于文件起始位置的偏移量（相对地址），这是因为编译器还不知道最终的内存布局，无法确定函数的绝对地址。在链接时，链接器将多个目标文件合并成一个可执行文件（.exe 或 .elf），链接器会为函数确定一个最终的地址。**函数的函数名就是函数的地址**。

```c
#include <stdio.h>

void myFunction() 
{
    printf("Hello, World!\n");
}

int main() 
{
    printf("Address of myFunction: %p\n", (void*)myFunction);
    return 0;
}
```
输出结果为

```c
Address of myFunction: 0x400526
```

我们知道在编译完成后，函数地址已经确认了，接下来我们看一下，在程序的执行过程中，程序如何通过地址来调用执行函数。
程序执行的本质时PC程序指针计数器不断加一，运行所指向内存单元的代码。当程序执行到函数部分时（即PC程序指针计数器指向函数时），发生函数调用。
第一步：调用者将参数压入栈中。（参数压入顺序通常根据调用约定不同，压入的方式也不同，常见的有cdecl、stdcall、fastcall）
第二步：调用者将返回地址（函数的下一条指令的地址）压入栈中。
第三步：PC程序指针计数器会更新为被调用函数的地址，从而跳转到函数的代码段执行。
第四步：函数，即被调用者创建**栈帧**（由序言代码执行完成）
 1. 将调用者的栈帧指针（ebp）压入栈。
 2. 设置新的栈帧基址（ebp = esp）。
 3. 为局部变量分配空间
 4. 保存重要寄存器的值
第五步：开始执行函数代码。
第六步：执行完毕后，将返回值存储到寄存器当中。释放栈帧，恢复调用者的栈帧指针。
第七步：从栈中弹出返回地址到PC指针计数器当中。至此函数调用完成，程序继续执行。
额外提及一点，在单片机的中断执行过程中，与程序函数调用过程类似，可以帮助理解。

## 函数的地址与函数的返回值
辨析：函数的地址与函数的返回值
```c
program(function1);		//这里传入program函数的是function1函数的地址
program(function1());	//这里传入program函数的是function1函数的返回值
```
二者仅有一对括号的差别，注意辨析。
第一个是为了在program函数中调用function1函数，第二个是先调用function1函数，如何将function1函数的返回值当作参数输入到program函数中去。

## 函数指针的声明
函数的函数名就是函数的地址，这一点已经被我们反复提及，如下：

```c
int function(int a, int b);
```
function就是地址
接下来我们来看函数指针的声明
```c
int function(int a, int b);
int (*pf)(int a, int b);
pf = function;
```
这里的pf就是函数function的指针

> 这时候大家可能会有疑惑，function是个地址，*pf所替换的是个地址的位置，而pf却被解释为了指针，对指针进行 * 运算（解应用运算）不应该得到的是pf这个指针所存储的地址的指向的内容的值吗，为什么是个地址？
> 这里笔者来给出解释，上文提过，**函数名就是函数的地址**这一点是不变的，但是由于函数本身是在程序段进行的存储，也就是代表着，对于“函数”的理解绝不能等同于数据的理解，实际上，函数名代表着函数本身，也是代表着函数的指针，也就是说 `function   *function    &function`这三者是完全等价的存在。

上面说的可能有点晕，我们也可以这么来理解函数指针，首先来看数据指针的定义过程。
```c
int   a = 0;
int* pa; 
pa = &a;
```
这里*并没有解引用的含义，有的仅仅是声明的含义。

同理，在函数指针的定义过程中，*也没有解引用的含义，有的仅仅是声明的含义。
```c
int function(int a, int b);
int (*pf)(int a, int b);
pf = function;//这里将function理解为了函数的地址
```

还有一种理解方式，将function理解为函数本身。
function是函数，那么(*pf)也是函数，(*pf)是个函数，pf就是指针，对指针进行解引用就得到了函数也就是(*pf)。
```c
int function(int a, int b);
int (*pf)(int a, int b);
pf = function;//这里将function理解为了函数本身
```

> 讲到这里，笔者也成功的将自己绕晕。其实本质上，**函数，函数的地址，函数的指针都是函数名，这三者是一个东西**。就是因为函数是存储在程序段当中的，所以无法将函数的地址运算方式同数据的地址运算方式对等起来。
> `function  ==  *function  ==   &function`

## 使用函数指针的调用函数

```c
int add (int a, int b);

int main()
{
	int (* pf) (int a, int b);
	pf = add;
	
	int test1 = add (1,2);
	int test2 = (*pf) (1,2);//使用*来对指针进行解引用得到函数

	return 0;
}

int add (int a, int b)
{
	return a+b;
}

```
实际上，下面这种调用函数也是正确的

```c
	int test3 =   pf  (1,2);//pf为指针，存储的是地址，地址即为函数名！！！
```

## 使用typedef为函数指针取别名
常见的typedef的使用方法为

```c
typedef 原类型 新类型名;
```
但是在函数指针这里略微不同，其语法格式为

```c
typedef 返回类型 (*函数指针)(参数列表);
typedef void (*PF)(int);  // 定义 PF为函数指针类型的别名
```
实际上，在这里原类型是 <kbd>返回类型 ( * )(参数列表)</kbd>即 <kbd>void ( * )(int) </kbd>，而新类型名则是对应<kbd>函数指针</kbd>即<kbd>PF</kbd>。
这样我们在创建一个void ( * )(int)形式的函数指针时就可以使用如下的形式

```c
PF pf;
//相当于以下形式
typedef void (*pf)(int); 
```



## 函数指针的工程应用---回调函数callback

```c
// 回调函数类型
typedef void (*Callback)(int);

// 接受回调函数作为参数的函数
void process(int value, Callback callback) 
{
    printf("Processing value: %d\n", value);
    callback(value);  // 调用回调函数
}

// 回调函数实现
void printValue(int value)
{
    printf("Callback: %d\n", value);
}

int main() 
{
    process(10, printValue);  // 传递函数指针
    return 0;
}
```
上述例子中使用了函数指针的方式创建回调函数，还有一种弱定义<kbd>__weak</kbd>的方式（相信学过STM32单片机HAL库一定不会对回调函数陌生），在HAL库中就是这种弱定义<kbd>__weak</kbd>的方式。
这篇文章主要是将函数指针的，所以在这里就不多赘述关于弱定义的内容了。
为什么要使用回调函数？
为了实现低耦合编程，代码之间的耦合度过高会导致难以移植修改等问题，使用回调函数就可以将部分的实现分离出去（比如在单片机中，中断处理的函数就是以回调函数的形式出现的，用户只需要修改回调函数满足功能即可，不用修改整个中断服务函数）
