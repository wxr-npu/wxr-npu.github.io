# 关于linux开机自启动
之前使用linux开机自启动通常是将bash脚本写入`/etc/rc.local`的方式，这两天学习了一种新的方法`systemd`，本文做简单介绍。

# 什么是systemd
`system`是系统，`d`是指`daemon`意思是守护进程，守护进程是一种后台长期运行、不跟终端绑定、默默提供服务的进程，通常d结尾。当中system是所有守护进程的父进程。
## PID=1
当linux系统启动的时候systemd作为第一个进程启动
![在这里插入图片描述](/images/blog/2026-03-09/01.png)可以使用htop查看进程与cpu核的使用情况，按t（tree）显示进程的树形结构
![在这里插入图片描述](/images/blog/2026-03-09/02.png)可以看到PID=1的进程就是systemd的进程（init）

也可以使用pstree指令查看

![在这里插入图片描述](/images/blog/2026-03-09/03.png)


## units
共11种
1. Service（服务单元，.service）----重点
2. Target（目标单元，.target）
3. Socket（套接字单元，.socket）
4. Device（设备单元，.device）
5. Mount（挂载单元，.mount）
6. Automount（自动挂载单元，.automount）
7. Swap（交换单元，.swap）
8. Path（路径单元，.path）
9. Timer（定时器单元，.timer）----重点
10. Slice（切片单元，.slice）
11. Scope（作用域单元，.scope）

这11种当中我们先介绍service，同时service也是我们开机自启动需要使用到的

# 命令

##  systemctl list-units
列出所有的units
```bash
systemctl list-units
systemctl list-unit-files# 查看文件
```
## systemctl status < 进程名 >
查看信息
```bash
systemctl status sshd
```
![在这里插入图片描述](/images/blog/2026-03-09/04.png)
1、当中`Loaded`表示的是是否启动开机自启动，后面的`enable`就是表示开启，`disable`表示关闭
2、当中`Active`表示的是当前是否运行，后面的`active（running）`表示正在运行，`inactive (dead)`表示关闭，`failed`表示失败。还有一种`active（waiting）`是定时器unit激活但是没有运行



## systemctl start < 进程名 >
修改Active，改变当前运行状态---开始



## systemctl stop < 进程名 >
修改Active，改变当前运行状态---停止



## systemctl enable < 进程名 >
修改Loaded，改变系统启动时的是否开机自启动---开机自启动



## systemctl disable < 进程名 >
修改Loaded，改变系统启动时的是否开机自启动---开机不自启动


## systemctl edit < 进程名 >
可以进行修改 并且支持报错

## sudo systemctl daemon-reload
刷新systemd配置

# systemd文件存储位置

## 1、/etc/systemd/---重要
自己写的放在这里，优先级最高

## 2、/lib/systemd
系统标准的systemd文件，出厂默认配置，更新软件时会被覆盖

## 3、/usr/lib/systemd
软件包自动安装的，包管理器管理

# 创建systemd的unit---service举例

```bash
[Unit]
Description=程序描述
After=network.target

[Service]
Type=simple
# User=用户名称
User=pi
# WorkingDirectory=程序所在目录（不是这个服务）
WorkingDirectory=/home/pi
# ExecStart=程序执行文件
ExecStart=/home/pi/hi.sh
#或者 ExecStart=/bin/bash -c "命令1 && 命令2 && 命令3"#相当于开启终端在里面输入
# ExecStart=/bin/bash -c "source /opt/ros/noetic/setup.bash && source /home/ubuntu/catkin_ws/devel/setup.bash && roslaunch tianbot_bringup tianbot_bringup.launch"

Restart=on-failure
RestartSec=2

[Install]
WantedBy=multi-user.target
```
