# 检查磁盘空间
首先需要检查磁盘空间大小，以防后续安装过程中磁盘空间不足导致安装失败
使用命令检查磁盘空间


```bash
df -h
```
![](/images/blog/2026-03-16/01.png)
图中的/dev/sda3代表的就是当前系统的磁盘空间大小，可以从图中看到我的磁盘空间总共分配了59G，已使用12G，剩余44G，对于编译内核绰绰有余。

> 关于其他文件
> 1、四个tmpfs表示临时文件系统（内存盘）
> 2、/dev/sda2表示启动分区（挂载在/boot上），用于存放内核镜像、启动配置文件等（EFI启动分区）
> 3、/dev/sr0表示光盘 / ISO 镜像挂载点

**建议可用空间：30 GB**


# 安装依赖环境

1、确保系统更新
使用如下命令

```bash
sudo apt update && sudo apt upgrade
```
2、安装开发环境

```bash
sudo apt install build-essential libncurses-dev flex bison libssl-dev libelf-dev bc dwarves rsync git
```



# 下载linux安装包
1、首先使用命令创建文件夹，防止后续文件混乱

```bash
mkdir mylinux
cd mylinux
```
2、使用命令下载linux安装包
三个选择一个即可

```bash
wget https://mirrors.tuna.tsinghua.edu.cn/kernel/v6.x/linux-6.9.2.tar.xz

wget https://mirrors.ustc.edu.cn/kernel/linux/kernel/v6.x/linux-6.9.2.tar.xz

wget https://mirrors.aliyun.com/linux-kernel/v6.x/linux-6.9.2.tar.xz
```
3、解压

```bash
tar -xvf linux-6.9.2.tar.xz
```
解压完成后使用df指令可以看到磁盘空间占用情况

![在这里插入图片描述](/images/blog/2026-03-16/02.png)
可以看到更新以及环境安装以及源码下载就用了3个G


4、进入解压目录

```bash
cd linux-6.9.2
```

# 编译
使用命令

```bash
make -j$(nproc)
```
调用cpu全部内核进行编译，此时会发现电脑的风扇在狂转是正常现象。
再编译完成之后我们再来看一下磁盘使用情况
```bash
df -h
```
![在这里插入图片描述](/images/blog/2026-03-16/15.png)
使用了39G，可以看出来磁盘空间消耗还是比较大的

# 安装内核

注意此时操作的文件目录为`~/mylinux/linux-6.9.2`
## 1、安装模块

```bash
sudo make modules_install
```
安装好的模块存放在`/lib/modules/<内核版本>`

![在这里插入图片描述](/images/blog/2026-03-16/16.png)


## 2、安装内核镜像

```bash
sudo make install
```
![在这里插入图片描述](/images/blog/2026-03-16/17.png)

这个命令会做三件事：

1、将内核镜像 vmlinuz-6.9.2复制到 /boot。
2、生成初始 RAM 磁盘镜像（initramfs），这在启动时用于加载必要的模块（如文件系统驱动）。
3、更新 GRUB 引导程序。旧内核：6.8.0-87 和 6.8.0-40 也保留作为备选


# 重新启动选择内核
```bash
sudo reboot
```
在开机时按住`esc`即可进入GRUB

选择新的内核即可启动

> 注意：这时启动之后可以看到原先的用户文件依然存在，这是正常的，原因是更换内核文件并没有更改用户的工作目录，仅仅是替换内核区
